# Cosplay 角色企划工作台（Character Planning Workbench）

辅助「从角色出发」的企划流程：选定角色 → 深度拆解 → 制定还原方案 → 规划拍摄 → 执行落地。不绑定个人装备，纯企划方法论，可套用于任意角色。

## 1. 角色档案（Character Dossier）

```markdown
# [角色名] 角色档案
- 出处：作品 / 作者 / 年代
- 身份：职业 / 阵营 / 背景故事（一句话）
- 性格关键词：______（如：凛然/温柔/狂气/忧郁）
- 气质定位：______（如：英气骑士王/孤傲女战神/邻家少女）
- 标志性元素：______（如：Saber呆毛、玛莲妮亚金臂）
- 名场面/经典动作：______（可作拍摄动作参考）
```

## 2. 设定图与三视图收集（Reference Collection）

**Cosplay 最重要的参考就是三视图**（正面/侧面/背面）——服装版型、假发结构、道具比例都从它来。

### 收集优先级
1. **官方设定图**：游戏官网 / Wiki（Fextralife等）/ 官方画集 / 模型内截图
2. **三视图**：正面 + 侧面 + 背面（+ 细节特写：假发结构、服装褶皱、道具纹样）
3. **优秀Cos正片**：真人还原效果参考（妆面/布料质感/上身效果）

### 主要收集平台
| 平台 | 用途 | 备注 |
|------|------|------|
| **Pixiv** | 官方图/同人设定图、三视图、细节拆分 | 画师设定稿最全；需代理 |
| **Bilibili** | **视频抽帧拿多角度（含背面）**、Coser正片 | **国内直连，勿设代理**（代理会触发412风控） |
| **小红书** | 真人Cos正片、妆造过程、道具测评 | 直连抓图方法见 memory |
| 游戏官网/Wiki | 官方立绘、模型图 | 最权威 |
| 游戏媒体站（游侠/3DM等） | 官方美图汇总页 | 批量下载立绘海报 |

### B站视频抽帧法（拿多角度视图的核心技巧）

游戏角色的官方宣传视频/干员档案视频通常包含**多角度角色展示**（正/侧/背），比静态图更全：

1. **搜索**：`api.bilibili.com/x/web-interface/wbi/search/type?search_type=video&keyword=<角色名> 立绘/档案/三视图`（国内直连，UA 带 Referer: bilibili.com）
2. **找官方账号视频**：如「《三角洲行动》干员档案-角色名」这类官方档案视频
3. **拿播放地址**：`api.bilibili.com/x/player/playurl?bvid=<BV>&cid=<cid>&qn=64&fnval=16` → dash.video 里取最高分辨率 baseUrl
4. **下载视频**：urllib + Referer 请求 baseUrl，保存 m4s/mp4
5. **抽帧**：用 PyAV（`pip install av`）按时间戳均匀抽帧（视频时长/n 个目标时间点，逐帧匹配 ±0.3s）
6. **vision 验证**：逐帧识别画面内容，挑出背面/侧面/道具特写帧

注意：本机 ffmpeg 可能因缺 x265 动态库不可用，PyAV 是更稳的替代。

### 归档规范
- **企划文档 + 参考图放同一文件夹**：`~/Desktop/<角色名>_企划/`（文档和图片同目录，方便整体分享）
- 命名：`官方立绘_正面` `三视图_背面` `细节_假发` `Cos正片_xxx` `官方档案帧_<秒>秒`
- **关键参考图嵌入 MD 文档**：`![描述](同文件夹相对路径/文件名)`，让企划文件自包含可分享
- 每张图记录来源（便于回查/授权确认）

## 3. 造型解构（Costume Deconstruction）

逐项拆解角色造型，每项都回答「角色特征是什么 → 怎么还原」：

### 发型（Hair）
- 发色 / 长度 / 发式（盘发？双马尾？直发？）
- 标志性细节（呆毛、刘海、发饰、辫子）
- 假发还原要点 + 定型需求

### 妆容（Makeup）
- 眼型基调（圆眼/细长眼/吊梢眼——决定眼线画法）
- 眉形（粗/细/挑/平）
- 唇色基调（正红/豆沙/裸色/深色）
- 妆面风格（清透/浓艳/烟熏/病娇）

### 服装（Costume）
- 主色系 / 材质 / 版型
- 层次结构（内搭/外套/裙摆/铠甲）
- 配饰（发饰/项链/手套/腰带）

### 道具（Props）
- 标志性武器/道具（Saber的咖喱棒、玛莲妮亚的义肢刀刃）
- 尺寸与材质建议

## 4. 还原方案（Reproduction Plan）

根据造型解构，制定可执行的还原步骤：
- 假发：选型 + 打理要点
- 妆容：逐部位妆面方案（眼妆重点/修容方向/唇妆）
- 服装：购买/定制/租借 + 尺寸注意
- 道具：购买 / 自制 / 3D打印
- 参考图：官方立绘 + 优质Cos正片对比研究

## 5. 拍摄企划（Shoot Plan）

### 场景（Location）
- 室内棚拍 / 户外 / 漫展 / 宅家自拍
- 背景与角色的色彩搭配

### 光线（Lighting）
- 主光位置与性质（硬光/柔光）
- 氛围光色彩（呼应角色主色系）
- 参考：一灯一板或三灯方案

### 镜头与动作（Camera & Pose）
- 镜头焦段 / 机位高度 / 景别
- 经典姿势参考（取自角色名场面）
- 表情管理（性格关键词→表情基调）

### 后期（Post）
- 调色方向（冷/暖/高对比/胶片感）
- 特效合成需求（羽翼/光效/场景替换）

## 6. 执行清单（Execution Checklist）

```
□ 角色档案完成
□ 三视图/官方设定图收集完毕（Pixiv/B站/小红书/官网）
□ 造型解构完成（发型/妆容/服装/道具）
□ 还原方案定稿
□ 假发/服装/道具下单或确认
□ 妆面方案定稿
□ 拍摄场景踩点/布景确认
□ 灯光方案确定
□ 试妆 + 试光完成
□ 正式拍摄
□ 后期 + 出片
```

- 官方档案视频：B站官方账号（抽帧拿多角度视图）
- 优质Cos：小红书笔记（直连抓图见 memory 中的小红书直连方法）、B站、微博

- 完整企划示例：`~/Desktop/麦晓雯_企划/`（三角洲行动·骇爪，含 B站抽帧法实战案例）
